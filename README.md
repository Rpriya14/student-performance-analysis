# Student Performance Data Analysis

## 📌 Project Objective

Analyzed student marks and attendance data using Python to understand performance trends across departments and student groups.

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib

## 📊 Analysis Performed

- Loaded and examined the student dataset
- Checked dataset structure and information
- Calculated average marks
- Identified the highest-scoring student
- Analyzed department-wise average marks
- Compared performance by gender
- Examined attendance and marks patterns
- Created bar chart visualizations

## 📈 Key Insights

- Identified the top-performing student
- Compared average performance across departments
- Compared average performance between gender groups
- Examined the relationship between attendance and marks

## 📂 Files

- `students1.csv` — Student marks and attendance dataset
- `student_performance_analysis.ipynb` — Python analysis notebook
