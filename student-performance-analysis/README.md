# Student Performance Data Analysis

## 📌 Project Objective
Analyze student marks and attendance data using Python to understand performance trends.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 📊 Analysis Performed
- Loaded CSV dataset
- Checked dataset info and structure
- Calculated average marks
- Found highest scoring student
- Department-wise average marks
- Gender-wise performance comparison
- Created bar chart visualization

## 📈 Key Insights
- Identified top performer
- Compared department performance
- Observed attendance vs marks trends
